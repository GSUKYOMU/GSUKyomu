강서대학교 교무처 수업관리

안내: 본 안내문은 성적평가, 입력 기준 및 제출서류 절차를 안내합니다. 자세한 문의는 교무처로 연락 주시기 바랍니다.

성적 평가는 아래의 기준에 따라 이루어지며, 평점평균(GPA)은 각 과목 평점×학점수를 합산 후 총 학점수로 나눈 값으로 산출됩니다.

  • P/F 평가 : 실습·현장 과목 등은 P(합격) 또는 F(불합격)으로 평가하며, 'P'는 GPA 계산에서 제외됩니다.
  • 결석 3분의 1 이상 시 해당 교과목은 F 처리됩니다.
  • 지각 3회는 결석 1회로 간주합니다.

제10조 (성적평가)

성적평가는 상대평가를 원칙으로 하며, 등급별 분포비율은 다음의 기준을 따릅니다. 단, 외국인 유학생의 성적평가는 이를 달리할 수 있습니다.

등급 평점 교양과목 전공과목
A+, A0 4.5 / 4.0 0 ~ 30% 0 ~ 35%
B+, B0 3.5 / 3.0 0 ~ 70% 0 ~ 80%
C+, C0 2.5 / 2.0 0 ~ 100% 0 ~ 100%
D+, D0 1.5 / 1.0 0 ~ 100% 0 ~ 100%
F 0.0 0 ~ 100% 0 ~ 100%
  • 중간·기말·과제·출석 점수의 합은 100점이 되도록 입력합니다.
  • 출석미달(결석 1/3 이상) 학생은 반드시 F 처리 후 ‘출석미달’로 표기해야 합니다.
  • “_”(미정)은 출결 미입력 상태로 간주되며 반드시 O/X/△ 중 하나로 수정해야 합니다.
  • 상대평가 제외 교과: 실습, 실기, 캡스톤디자인, 마이크로디그리, 수강생 10명 이하 교과 등.
  • 성적보고서 1부 : 성적 정정 마감 이후 출력, 담당교수 서명 필수.
  • 출석부 1부 : 전자출결시스템 출력본, 서명 필수.
  • CQI(강의개선보고서) : 인트라넷 입력, 별도 제출 불필요.
  • 조기취업 학생의 경우 출석인정확인서 및 재직증빙서류 동시 제출.

모든 서류는 서명·날인 후 교무처로 직접 또는 우편 제출해야 합니다.

주소: (07661) 서울시 강서구 까치산로 24길 47 본관 1층 교무과 수업담당자

성적 정정 마감일 기준 2일 이내 도착분까지 인정됩니다.

  • 성적 입력 기한을 반드시 준수해야 하며, 미입력 시 F 처리될 수 있습니다.
  • 모든 성적 근거 자료는 10년간 보관해야 합니다.
  • CQI 보고서는 교육과정 개선 및 대학평가에 활용됩니다.
