• P/F 평가: 현장 실습과 같이 등급별 평가가 어려운 과목의 경우 ‘P’(합격) 또는 ‘F’(불합격)로 평가하며, 'P'는 평점평균 산출에서 제외됩니다.

몇 회 결석부터 F인가요?

- 학생이 한 학기 수업 시간수의 3분의 1 이상을 결석한 과목에 대해서는 그 학점을 인정하지 않으며, 담당 교수가 급제 성적을 부여했더라도 교무처에서 직권으로 성적을 취소(과락 처리)합니다.

- 추가로 지각 3회는 1회의 결석으로 처리됩니다.

  1. 중간·기말고사, 과제물, 출석성적 합을 100점이 되도록 기재해 주시기 바랍니다.
    (예) 출석 10%, 중간고사 30%, 기말고사 40%, 과제 20% → 합계 100%
    출석 15회(만점), 중간고사 80점(×30%), 기말고사 90점(×40%), 과제 70점(×20%)
    출석 10점 + 중간 24점 + 기말 36점 + 과제 14점 = 84점 (B학점)
  2. 결석이 수업일수의 1/3 이상 되는 학생은 반드시 F처리해 주시고 성적보고서 비고란에 출석미달로 기재하기 바랍니다.
    ➀ 출결체크 상태: 출석 O / 결석 X / 지각 △
    ➁ 총 수업시수의 1/3 이상 결시자 → 출석미달로 반드시 F
    (예: 3시간 수업 → 총 45시간, 결석 15시간 이상이면 F)
    ③ “_(미정)” 시수는 출결 미진행으로 간주 → 반드시 O/X/△ 중 하나로 입력
  1. 실습과목: 교내/외 현장교육 60% 이상 참여하는 경우.
  2. 실기과목.
  3. 캡스톤디자인과목.
  4. 융합, 마이크로디그리 교과.
  5. 외부 전문평가자 과목: 평가점수의 30% 이상 외부 평가 반영.
  6. 수강인원 10명 이하의 강좌.
  7. 기타 총장이 인정하는 교과목.
  8. PASS 과목 및 실습/실기과목 (학칙 시행세칙 명시).
  9. 외국인 유학생의 성적평가는 달리 적용 가능.

성적평가는 상대평가를 원칙으로 합니다.

필수 제출 서류:

  • 성적보고서 1부 (성적 정정 마감일 이후 출력 → ‘담당교수’란에 서명 필수)
  • 출석부 1부 (전자출결시스템 출력 → ‘서명’란에 서명 필수)
  • 강의개선보고서(CQI) (학사인트라넷에서 입력 → 제출 불필요)

해당 교수만 제출:

  • 조기취업 학생 관련 자료 (성적보고서·출석부와 동시 제출)
    - 1) 출석인정확인서
    - 2) 재직증빙서류
    → 학기말 기준 자료인지 반드시 확인!

반드시 서명·날인 후 교무처로 직접 또는 우편으로 송부하여 주시기 바랍니다.

→ 제출 마감일 발송 기준 2일 이내 도착하도록 빠른등기로 발송 바랍니다.

주소: (07661) 서울시 강서구 까치산로 24길 47 강서대학교 본관 1층 교무과 수업담당자

모든 성적 근거 자료는 10년간 교수님께서 보관하셔야 합니다.

  1. 과제물 성적은 성적입력마감일 이전에 정리하여 기일 내 제출 가능하도록 지도바랍니다.
  2. 성적 미입력 시 F 처리 → 장학금 등 혜택 상실 가능성 있음. 기한 엄수 필수!
  3. 교무처 제출 서류 외 과제·시험지 등은 10년간 보관 (성적 이의 시 확인용).
  4. 성적보고서는 성적정정일 이후 출력본만 인정. 이전 출력본은 무효.
  5. 조기취업 학생의 대체학습 이행 여부 반드시 확인. 미이행 시 출석인정 불가.
  6. CQI는 교육과정 개발 및 대학평가에 활용되오니 정성껏 작성 부탁드립니다.

가. 성적 잘못입력 - A교수

→ 무작위 정정으로 고득점자 성적 하락 → 교원업적평가 반영 + 차기 강의배정 제한

나. 출석점수 착오 - B교수

→ 출석 완료 학생에게 1점 부여 → 성적정정 후 강의배정 제한

다. 절대평가 적용 오류 - C/D교수

→ 수준별 분반 수업임에도 절대평가 → 상대평가로 재정정

라. 출석미달 학생 성적 부여 - E교수

→ 교무처 직권 과락 처리

※ 기타 사례도 유사하게 본인 실수 인정 → 정정 → 강의배정 제한 조치됨

→ 성적 입력 및 정정 기한 철저히 준수하시기 바랍니다.
