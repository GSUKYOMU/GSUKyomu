전자출결 입력 기준 및 출결 관리 안내

안내: 출석은 학점 인정의 기본 요건입니다. 담당교수(또는 강사)는 전자출결시스템(헤이영)을 통해 출석을 입력해야 합니다. 수업 시작 전에 반드시 출석이 확인되어야 하며, 당일 출석 처리를 진행하지 않은 경우 결강으로 간주됩니다.

출석은 헤이영(HeYoung)을 통해 자동 인식됩니다. 전자출결 입력은 앱 또는 PC 버전 중 편한 방법으로 진행할 수 있습니다.

📱 앱(HeYoung App) 이용 시

  • 전자출결 앱 접속 → 메인화면 → 전자출결 보러가기 → 출결진행
  • 당일 수업은 수업 시작 10분 전부터 메인화면에 노출됩니다.
  • 수업이 있는 날이라도 해당 시간이 되지 않으면 표시되지 않습니다.

💻 PC(HeYoung Web) 이용 시

  • 전자출결 PC(헤이영) 접속 → 강좌별출석관리 → 해당 과목 선택 → 출결 진행

⚙️ 출석 처리는 반드시 수업 시작 전까지 완료해야 하며, 미처리 시 해당 강의는 결강으로 간주됩니다.

전자출결시스템(헤이영)에서는 아래와 같이 출석 상태를 구분합니다.

  • 10분 이상 지각, 수업 중 무단 퇴실, 수업 불참은 모두 결석으로 처리합니다.
  • 지각 3회는 결석 1회로 간주합니다.
  • 출석 확인은 수업 시작 전까지 완료해야 하며, 미처리 시 결강으로 간주합니다.
