출석 관련 안내

출석기준, 전자출결, 공결·유고결석 및 인정 절차 안내

안내: 출석은 학점인정의 기본 요건으로, 수업시간의 3분의 1 이상 결석 시 학점이 부여되지 않습니다. 전자출결 시스템을 통해 자동 관리되며, 결석·지각 처리 기준을 꼭 확인하시기 바랍니다.

  • 출석은 전자출결시스템을 통해 관리됩니다.
  • 결석이 수업시수의 3분의 1 이상인 경우 성적이 인정되지 않으며 F 처리됩니다.
  • 지각 3회 = 1회 결석으로 간주됩니다.
  • 출석체크 누락·오류 발생 시, 해당 교수님께 즉시 확인 요청 바랍니다.

출석은 비콘(Beacon) 또는 QR코드를 통해 자동 인식됩니다.

  1. 스마트폰의 블루투스·위치정보 기능을 켭니다.
  2. 전자출결 앱 실행 → 강의 선택 → 자동 출석 확인
  3. 출석 누락 시 교수님께 요청하여 수동 출석 인정 가능

출석 오류는 수업일 또는 익일 내에 반드시 확인 요청해야 합니다.

  1. 학사인트라넷 → 학생서비스 → 유고결석 신청
  2. 결석 사유 증빙서류 첨부 (예: 진단서, 가족관계증명서, 사망진단서 등)
  3. 지도교수 승인 → 학과장 확인 → 교무처 승인

유고결석이 승인되면 해당 결석은 출석으로 처리되지만, 성적 평가에는 반영되지 않습니다.

  • 조기취업자: 조기취업계 및 재직증명서 제출 → 학과 및 교무처 승인
  • 장애학생: 장애학생지원센터 확인 후 학과 승인
  • 학교 공식행사: 담당 부서의 공문 또는 참석확인서로 인정 가능
출석 관련 신청서 양식 다운로드 (HWP)
  • 수업 시작 15분 이후 입실 시 ‘지각’ 처리됩니다.
  • 출석 오류 정정은 수업 주차 내에서만 가능합니다.
  • 유고결석 신청은 사유 발생 즉시 제출해야 하며, 사후 제출은 불인정될 수 있습니다.
